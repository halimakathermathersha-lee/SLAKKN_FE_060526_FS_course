React Interview Questions

1. What is DOM?

DOM (Document Object Model) is a tree-like structure created by the browser from an HTML document. It allows JavaScript to access, modify, add, or remove HTML elements dynamically.

Example:

<p id="demo">Hello</p>

<script>
document.getElementById("demo").innerText = "Welcome";
</script>

Real-time Example:

When you click a button and the text, color, or image changes without refreshing the page, JavaScript is manipulating the DOM.

2. What is React?

React is a JavaScript library used to build fast, interactive, and reusable user interfaces (UI), especially for Single Page Applications (SPA).

Features:

  • Component-based architecture
  • Uses Virtual DOM for faster updates
  • Reusable code
  • Easy to maintain
  • One-way data flow

Real-time Examples:

  • Facebook
  • Instagram
  • Netflix
  • WhatsApp Web

3. What are Components?

A Component is a reusable piece of UI in React. Each component contains its own HTML (JSX), CSS, and JavaScript logic.

Instead of writing the same code multiple times, you create one component and reuse it wherever needed.

Example:

function Header() {
    return <h1>Welcome</h1>;
}

Real-time Example:

  • Header Component
  • Navbar Component
  • Product Card Component
  • Footer Component

4. What are Functions?

A Function is a block of code that performs a specific task. It runs only when it is called.

Syntax:

function greet() {
    console.log("Hello");
}

greet();

Output:

Hello

Function with Parameters:

function add(a, b) {
    return a + b;
}

console.log(add(10, 20));

Output:

30

Real-time Example:

function calculateTotal(price, quantity) {
    return price * quantity;
}

Interview One-Line Answers

  • DOM: The Document Object Model is a tree structure of an HTML page that allows JavaScript to access and modify web page elements.
  • React: React is a JavaScript library used to build fast, interactive, and reusable user interfaces.
  • Component: A component is a reusable piece of UI in React that contains its own structure and logic.
  • Function: A function is a reusable block of code that performs a specific task when called.
