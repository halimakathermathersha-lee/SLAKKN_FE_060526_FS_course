JS Variables

1. What is Variable?

A variable is used to store data values.

2. What is Declaration?

Creating a variable is called declaration.

3. What is Initialization?

Assigning a value to a variable is called initialization.

4. 3 Types of Keywords in JS

  • var
  • let
  • const

5. What is Compiler in JS and its Name?

JavaScript uses engines to run code.

  • V8 - Chrome
  • SpiderMonkey - Firefox
  • JavaScriptCore - Safari

6. What are Printing Statements?

  • console.log()
  • document.write()
  • alert()
