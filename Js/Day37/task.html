Most Important Interview Questions

1. Why Callback?

A callback is a function passed as an argument to another function. It is used to execute code after another function has completed.

Why do we use it?

  • To perform asynchronous operations.
  • To ensure one task finishes before another starts.

Example


function greet(name, callback) {
    console.log("Hello " + name);
    callback();
}

function bye() {
    console.log("Goodbye!");
}

greet("Halima", bye);

2. Why Promise?

A Promise is an object that represents the eventual completion (or failure) of an asynchronous operation.

Why do we use it?

  • To solve Callback Hell.
  • To make asynchronous code easier to manage.
  • To provide better error handling.

Example


const promise = new Promise((resolve, reject) => {
    let success = true;

    if (success) {
        resolve("Data Loaded");
    } else {
        reject("Error");
    }
});

promise
.then(result => console.log(result))
.catch(error => console.log(error));

3. Why Async/Await?

async/await is a cleaner way to work with Promises. It makes asynchronous code look like normal synchronous code.

Why do we use it?

  • Cleaner code.
  • Easier to read.
  • Easier to debug.
  • No long .then() chains.

Example


function getData() {
    return new Promise(resolve => {
        setTimeout(() => {
            resolve("Data Received");
        }, 2000);
    });
}

async function display() {
    const result = await getData();
    console.log(result);
}

display();

4. Why Fetch?

fetch() is used to communicate with APIs. It sends requests and receives data from a server.

Why do we use it?

  • Retrieve data (GET).
  • Send data (POST).
  • Update data (PUT).
  • Delete data (DELETE).

Example


fetch("https://jsonplaceholder.typicode.com/users")
.then(response => response.json())
.then(data => console.log(data))
.catch(error => console.log(error));

Quick Interview Answers

Why Callback?
To execute a function after another function completes, especially for asynchronous operations.

Why Promise?
To avoid Callback Hell and handle asynchronous operations more effectively.

Why Async/Await?
To write Promise-based code in a cleaner, more readable, synchronous-looking style.

Why Fetch?
To communicate with APIs by sending requests and receiving data from servers.
