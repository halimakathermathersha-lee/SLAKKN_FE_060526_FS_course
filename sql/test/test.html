SQL Interview Questions and Answers

Basic Level - Questions 1 to 5

Question 1: What is the difference between DBMS and RDBMS?

Answer: DBMS stands for Database Management System. It is software used to store, manage, update and retrieve data.

RDBMS stands for Relational Database Management System. It is a type of DBMS that stores data in the form of tables with rows and columns. RDBMS also supports relationships between tables using keys.

Examples of RDBMS are MySQL, Oracle, PostgreSQL and SQL Server.

Question 2: Explain DDL, DML, DQL, DCL and TCL.

DDL - Data Definition Language: DDL is used to create and modify the structure of database objects. Examples: CREATE, ALTER, DROP and TRUNCATE.

DML - Data Manipulation Language: DML is used to insert, update and delete data from tables. Examples: INSERT, UPDATE and DELETE.

DQL - Data Query Language: DQL is used to retrieve data from a database. Example: SELECT.

DCL - Data Control Language: DCL is used to control database permissions. Examples: GRANT and REVOKE.

TCL - Transaction Control Language: TCL is used to manage database transactions. Examples: COMMIT, ROLLBACK and SAVEPOINT.

Question 4: What is the difference between DELETE, TRUNCATE and DROP?

DELETE: DELETE is used to remove specific records or all records from a table. The table structure remains. 

DELETE FROM Employees
WHERE id = 3;

TRUNCATE: TRUNCATE removes all records from a table but keeps the table structure. 

TRUNCATE TABLE Employees;

DROP: DROP completely removes the table including its data and structure. 

DROP TABLE Employees;

Question 5: What is the difference between CHAR and VARCHAR?

CHAR: CHAR is used to store fixed-length character data. It is suitable when the length of the value is fixed.

Example: gender CHAR(1)

VARCHAR: VARCHAR is used to store variable-length character data. It is suitable for names, emails, cities and addresses.

Example: name VARCHAR(50)

Question 9: What is the difference between WHERE and HAVING?

Answer: WHERE is used to filter individual rows before grouping. HAVING is used to filter groups after GROUP BY.

WHERE Example:

SELECT * FROM Employees
WHERE salary > 50000;

HAVING Example:

SELECT department, COUNT(*)
FROM Employees
GROUP BY department
HAVING COUNT(*) > 2;

Question 11: Generate a Department Report using GROUP BY.

SELECT
    department,
    COUNT(*) AS employee_count,
    SUM(salary) AS total_salary,
    AVG(salary) AS average_salary
FROM Employees
GROUP BY department;

Question 12: Display departments using HAVING.

Departments having more than 3 employees:

SELECT department, COUNT(*) AS employee_count
FROM Employees
GROUP BY department
HAVING COUNT(*) > 3;

Average salary greater than 50000:

SELECT department, AVG(salary) AS average_salary
FROM Employees
GROUP BY department
HAVING AVG(salary) > 50000;

Question 15: Interview Challenge

SELECT
    department,
    COUNT(*) AS employee_count,
    SUM(salary) AS total_salary,
    AVG(salary) AS average_salary,
    MAX(salary) AS highest_salary,
    MIN(salary) AS lowest_salary
FROM Employees
WHERE salary > 40000
AND city = 'Chennai'
GROUP BY department
HAVING COUNT(*) > 2
AND AVG(salary) > 60000
ORDER BY total_salary DESC
LIMIT 3;

Bonus Interview Questions

1. What is the difference between COUNT(*) and COUNT(column)?

Answer: COUNT(*) counts all rows in the table. COUNT(column) counts only the non-NULL values in the specified column.

2. Can HAVING be used without GROUP BY?

Answer: Yes. HAVING can be used without GROUP BY, especially when filtering an aggregate result. 

SELECT AVG(salary)
FROM Employees
HAVING AVG(salary) > 50000;

3. Can WHERE and HAVING be used together?

Answer: Yes. WHERE filters individual rows before grouping and HAVING filters groups after GROUP BY. 

SELECT department, AVG(salary)
FROM Employees
WHERE salary > 40000
GROUP BY department
HAVING AVG(salary) > 50000;

4. What is the execution order of a SQL query?

Answer: The simplified logical execution order of a SQL query is:

FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT

5. Which executes first: WHERE or GROUP BY?

Answer: WHERE executes before GROUP BY.

First, WHERE filters individual rows. Then GROUP BY groups the remaining records. Finally, HAVING can be used to filter those groups.

Remember: WHERE filters rows before grouping, while HAVING filters groups after grouping.
